How to add it to Gmail
  1. Select everything inside the dashed box below (click and drag from the logo to the last line), then copy (Ctrl+C).
  2. In Gmail: Settings → See all settings → General → Signature → Create new, name it "Tafutakazi".
  3. Click in the signature box and paste (Ctrl+V). The logo shows once the site is live.
  4. Under "Signature defaults", pick it for hello@tafutakazi.co.ke (new emails and replies), then Save changes at the bottom.
